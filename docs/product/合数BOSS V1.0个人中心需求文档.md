## 1. 需求说明

个人中心为当前登录用户提供个人资料维护、登录密码修改、外部账号绑定和导出文件查询能力。一级菜单“个人中心”位于“业务配置”上方，包含“用户信息”和“我的下载”两个二级菜单；点击页面右上角用户名区域的“个人中心”可直接进入“用户信息”。

本模块只处理当前登录账号自身的信息与任务，不替代系统管理中的员工主档、组织权限或外部平台配置。页面、接口、下载内容和绑定记录均需按当前登录账号鉴权。

## 2. 信息架构与入口

| 入口 | 目标页面 | 规则 |
|---|---|---|
| 左侧导航—个人中心—用户信息 | `/personal/profile` | 打开用户信息页，默认显示“基本设置” |
| 左侧导航—个人中心—我的下载 | `/personal/downloads` | 打开当前权限范围内的下载任务列表 |
| 右上角用户名—个人中心 | `/personal/profile` | 收起用户菜单并直接进入用户信息页 |

个人中心无权限时不展示左侧菜单入口；直接访问路由时由服务端返回无权限，不得只依赖前端隐藏。

## 3. 用户信息

### 3.1 页面结构

页面左侧展示当前用户只读信息，右侧通过“基本设置、密码设置、外部绑定”三个页签维护可编辑信息。

| 区域 | 字段/功能 | 规则 |
|---|---|---|
| 个人信息卡片 | 头像、用户名称、用户编号、所属角色、手机号码、用户邮箱、所属部门、所属岗位、入职日期、创建时间、本次登录 | 数据来自当前登录账号及关联员工主档；用户编号、角色、部门、岗位和日期均只读 |
| 基本设置 | 用户名称、用户手机、用户邮箱、用户性别 | 四项必填；名称最长32字符，手机号最长20字符，邮箱最长80字符；保存成功后刷新右上角用户信息 |
| 密码设置 | 旧密码、新密码、确认密码 | 三项必填；新密码至少8位；两次新密码必须一致；服务端校验旧密码并记录安全审计 |
| 外部绑定 | 绑定平台、标识、昵称、解绑 | 统一更名为“外部绑定”；不展示单账号只能绑定一个企业微信的说明 |

### 3.2 外部绑定规则

1. 一个合数BOSS账号允许绑定多个企业微信身份；页面以列表展示全部当前有效绑定，不设置账号侧唯一数量限制。
2. 同一外部身份仍需全局唯一：同一 `CorpID + UserID` 同一时刻只能绑定一个合数BOSS账号，避免身份冒用和登录冲突。
3. 绑定记录至少保存平台、租户/CorpID、外部用户标识、昵称、绑定状态、绑定时间和操作人；`CorpID + UserID` 不作为合数BOSS用户或员工主键。
4. 解绑属于高风险操作，需二次确认并记录操作人、时间、原因和原绑定快照；解绑只结束当前关系，不物理删除历史。
5. 空状态显示“暂无外部绑定”；加载失败应提供重试，不得以空状态掩盖接口异常。

## 4. 我的下载

### 4.1 页面目标

统一查询导出任务、生成进度及下载记录。列表默认按申请时间倒序展示；用户只能看到其数据权限范围内的任务，服务人和部门筛选只缩小可见范围，不能扩大权限。

### 4.2 查询条件

| 条件 | 交互及规则 |
|---|---|
| 服务人 | 单选、可清空；候选项按当前用户数据权限裁剪 |
| 部门 | 单选、可清空；支持按授权组织范围选择 |
| 综合搜索 | 支持按申请人或文件名称模糊搜索 |
| 申请时间 | 支持昨天、今天、本周、上周、本月、上月、本季度、上季度、本年、去年快捷选择，也支持自定义开始和结束日期 |
| 生成状态 | 仅包含“已生成、生成中、生成失败”，不提供“已过期”状态 |
| 查询/重置 | 查询按组合条件刷新列表；重置清空服务人、部门、关键词、时间、状态及快捷时间选中态 |

页面说明固定为“文件生成需要一点时间，可以点击刷新查看最新状态。”不展示“生成成功后通过企业微信通知”的承诺。点击“刷新”重新获取任务状态；刷新成功、无变化或失败均需给出明确反馈。

### 4.3 列表字段与操作

| 字段 | 说明 |
|---|---|
| 申请人 | 发起导出任务的用户名称 |
| 所属部门 | 任务发起时申请人的部门快照；人员调岗后不回写历史任务 |
| 申请时间 | 任务成功受理时间，支持排序 |
| 文件内容名称 | 文件名称，并辅助展示来源模块及文件大小 |
| 下载次数 | 成功触发文件下载的累计次数 |
| 状态 | 已生成、生成中、生成失败 |
| 操作 | 固定在表格最右侧，包含“下载、记录” |

- “下载”仅在状态为“已生成”时可用；生成中和生成失败状态禁用。
- 点击“下载”后校验文件权限与当前任务状态，成功后增加下载次数并记录下载审计。
- 点击“记录”打开详情，展示申请人、所属部门、文件名称、申请时间、生成时间和下载次数。
- 空状态显示“暂无符合条件的下载任务”；分页显示当前筛选结果总数。

### 4.4 异步任务与异常

导出任务至少保存任务ID、申请人账号ID、申请人/部门快照、来源模块、筛选条件快照、文件名称、申请时间、生成时间、文件大小、下载次数、状态、失败原因和文件存储引用。重复刷新不得重复创建任务；重复下载只增加下载记录，不生成新文件。生成失败时保留失败原因和重试依据，但本页面当前不提供重试按钮，用户需返回来源模块重新发起导出。

## 5. 权限与审计

| 权限 | 控制点 |
|---|---|
| `personal.profile.view` | 查看本人用户信息 |
| `personal.profile.edit` | 修改本人基本资料 |
| `personal.password.change` | 修改本人密码 |
| `personal.binding.manage` | 查看、绑定和解绑本人外部账号 |
| `personal.download.view` | 查看授权范围内的下载任务 |
| `personal.download.file` | 下载已生成文件 |

基本资料修改、密码修改、外部身份绑定/解绑和文件下载必须记录审计。日志不得保存密码、完整令牌或文件临时签名地址；手机号、邮箱及外部标识按权限脱敏。

## 6. 验收标准

1. 左侧个人中心位于业务配置上方，且右上角用户名入口可进入用户信息页。
2. 用户信息三个页签显示正确；原“企微绑定”文案及单账号单企微说明均不再出现。
3. 同一账号可同时展示多个企业微信身份，同一 `CorpID + UserID` 不可绑定到多个账号。
4. 我的下载可组合使用服务人、部门、关键词、申请时间和状态筛选，重置后恢复默认结果。
5. 状态枚举仅为已生成、生成中、生成失败，不出现已过期。
6. 表格展示申请人和所属部门，操作列固定在最右侧；下载和记录交互符合状态约束。
7. 页面说明不包含企业微信通知承诺，刷新能更新生成中任务并给出结果反馈。
8. 无权限、加载失败、空数据和下载失效场景均有明确反馈，不发生越权查看或下载。

## 7. 回滚策略

- 页面异常时可关闭个人中心菜单权限并回退上一版前端，不删除用户资料、绑定关系、绑定历史、导出任务或下载审计。
- 多外部身份能力回滚时仅关闭新增绑定入口，不得直接恢复账号侧唯一约束或删除已存在的多条有效绑定；待数据评估与补偿方案确认后再迁移。
- 下载功能异常时关闭下载入口，保留任务和文件元数据；修复后按原任务ID恢复访问。
