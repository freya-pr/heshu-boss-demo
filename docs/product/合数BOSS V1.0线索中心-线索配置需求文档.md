# 合数BOSS V1.0线索中心－线索配置需求文档

> 模块：线索中心 / 线索配置
> 版本：V1.1（独立细化版）
> 状态：已确认
> 更新日期：2026-10-21
> 上位基线：《合数BOSS V1.0线索中心需求文档》

## 1. 模块定位

线索配置用于查看“家庭教育需求问卷规则”的等级判定逻辑及版本状态。V1.0 采用固定规则，不开放通用规则编排能力。

## 2. 范围边界

- 仅保留“家庭教育需求问卷规则”一条等级规则；
- 仅展示“全部规则、等级规则”两个分类；
- 不提供新增、编辑、复制为草稿、试算和冲突检测入口；
- 支持查看详情、版本记录、启停与版本回退；
- 活码分配和营期名单流转由各自业务模块维护，不在线索配置中展示。

## 3. 页面结构

| 页面区域 | 功能要求 |
|---|---|
| 汇总信息 | 展示规则总数、已发布数量和待完善草稿数量 |
| 规则分类 | 仅展示全部规则、等级规则及数量 |
| 查询区 | 支持按名称/编号/条件/动作、状态和触发方式查询 |
| 规则列表 | 展示规则名称、编号、版本、规则链、适用范围、优先级、状态和最后更新信息 |
| 操作区 | 仅提供详情和“更多”；更多中提供版本记录、启用或停用 |
| 规则详情 | 展示当前版本的触发条件、分数区间、执行动作、适用范围和更新时间 |

## 4. 固定等级规则

| 项目 | 规则 |
|---|---|
| 规则名称 | 家庭教育需求问卷规则 |
| 触发条件 | 有效问卷提交或重新解析 |
| S级 | 总分 ≥ 90 |
| A级 | 75—89 |
| B级 | 60—74 |
| C级 | 低于 60 |
| 执行动作 | 生成线索等级并写入评级历史 |
| 适用范围 | 一转业务有效问卷 |

人工等级优先于自动结果。人工结果解除前，后续问卷重算只能生成候选结果，不得覆盖当前有效等级。

## 5. 版本与状态

1. 已发布版本不可被直接覆盖；
2. 停用仅阻止后续自动评级，不回滚历史评级结果；
3. 版本回退必须形成新版本，并保留回退前后版本、操作人、时间和原因；
4. 规则执行必须记录规则编号、版本、答卷编号、输入快照、命中区间、输出等级和执行时间。

## 6. 权限与审计

| 权限 | 说明 |
|---|---|
| `lead_rule:view` | 查看列表与详情 |
| `lead_rule:version:view` | 查看版本记录 |
| `lead_rule:status:update` | 启用或停用规则 |
| `lead_rule:rollback` | 发起版本回退 |

启停和版本回退均须写入审计日志；列表查询和详情查看不产生业务变更。

## 7. 验收标准

- [ ] 页面仅展示一条“家庭教育需求问卷规则”；
- [ ] 页面不出现新增、编辑、复制、试算和冲突检测入口；
- [ ] 详情、版本记录、启停和版本回退可按权限使用；
- [ ] S/A/B/C 分数区间与问卷管理、线索列表和客户等级口径一致；
- [ ] 历史版本和历史评级结果不会因启停或回退被覆盖或删除。
