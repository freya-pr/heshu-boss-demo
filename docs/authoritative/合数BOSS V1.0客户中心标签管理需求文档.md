> 本文是“客户中心—企微标签”的专项需求入口。当前页面仅管理企微企业标签，不展示系统标签来源，不提供企微个人标签模块。线索、客户、问卷和活码页面只消费当前用户有权使用的企微标签，不在这些页面维护标签定义。

## 1. 需求范围

企微标签以企业微信为主数据源，合数BOSS按当前企业主体展示和维护企微企业标签组及标签。在本页新增、编辑或删除后同步到当前企业主体；点击“同步企微标签”可拉取企业微信最新数据并刷新本地映射。

V1.0包含：

- 标签组列表、名称搜索、新增、编辑、单条删除和空分组批量删除；
- 标签组适用部门多选及快捷编辑；
- 当前分组标签列表、单条/批量新增、编辑和删除；
- 全局标签搜索、使用客户下钻及企微同步；
- 当前企业主体隔离、权限校验、幂等、异常反馈和审计。

V1.0不包含：

- 系统标签来源及系统标签管理；
- 企微个人标签模块；
- 标签规则、AI标签、外部SCRM标签映射或标签治理中心；
- 标签操作日志、同步历史的独立查询页面。

## 2. 页面入口与布局

- 页面入口：客户中心—企微标签；路由 `/customers/tags`。
- 页面标题：企微标签；说明为“按企业微信标签组维护企微企业标签，页面数据与当前企业主体保持同步”。
- 顶部展示当前主体下标签组总数、标签总数及“同步企微标签”按钮。
- 页面提示企业微信为标签主数据源，在本页新增、编辑或删除后会同步至当前企业主体。
- 页面采用左右布局：左侧为标签分组，右侧为当前分组标签。
- 默认选择第一个可见标签组；无标签组时展示空状态并保留新增分组入口。

## 3. 标签分组

### 3.1 分组列表与搜索

| 字段 | 规则 |
|---|---|
| 分组名称 | 展示标签组名称及组内标签数量；点击切换右侧标签列表 |
| 适用部门 | 展示“全部部门”或多个部门名称；点击可直接打开编辑标签分组弹窗 |
| 更多 | 点击三个点展示“编辑、删除” |

- “新增分组”旁提供搜索图标；点击后展开“搜索标签分组名称”输入框。
- 搜索按分组名称模糊匹配；清空或关闭搜索恢复全部分组。
- 无匹配结果时显示“未找到匹配的标签分组”。

### 3.2 新增分组

| 字段 | 必填 | 规则 |
|---|---:|---|
| 分组名称 | 是 | 最多15个字；当前企业主体内名称不可重复 |
| 适用部门 | 是 | 组织树多选；至少选择一个部门；支持搜索、展开、勾选和移除 |
| 标签 | 是 | 至少新增一个标签；单个标签最多15个字，分组内不可重名 |

- “全部部门”与具体部门互斥；选择具体部门后自动移除“全部部门”，重新选择“全部部门”时清空其他选择。
- 所选部门均可使用及编辑该分组下的企微标签。
- 标签可逐个录入后点击加号添加，也可点击“批量新建”。
- 批量新建每行输入一个标签，回车换行；自动去除空行及本次输入中的重复项。
- 保存失败时保留输入并展示明确原因；成功后新增分组置于列表前部、自动选中，并将标签同步至当前企业主体。

### 3.3 编辑分组

- 点击分组的适用部门或更多菜单中的“编辑”进入编辑弹窗。
- 支持修改分组名称和适用部门；分组名称仍受15字及主体内唯一校验。
- 适用部门至少保留一个；保存成功后立即刷新左侧摘要和右侧标题下方部门信息。
- 编辑分组不直接增删组内标签，标签维护使用右侧标签操作。

### 3.4 删除与批量删除

- 只有标签数量为0的空分组允许删除。
- 非空分组点击删除时提示“请先清空分组下内容再删除分组！”，不得继续。
- 空分组单条删除需二次确认。
- “新增分组”右侧提供批量删除按钮；点击后进入批量选择模式。
- 批量模式只允许勾选空分组，非空分组复选框禁用并说明原因。
- 未选择分组时提示“请至少选择一个空分组”；确认后一次删除所选空分组并刷新当前选择。
- 删除请求按主体和分组ID幂等；重复请求不得删除其他主体或已重新创建的同名分组。

## 4. 当前分组标签

### 4.1 列表字段

| 字段 | 规则 |
|---|---|
| 标签 | 展示标签名称，名称下方展示企业微信标签ID |
| 使用客户 | 展示使用该标签的客户数，支持排序并可点击下钻 |
| 创建人 | 展示创建时人员名称快照 |
| 更新时间 | 展示最近一次成功同步或编辑时间 |
| 操作 | 固定右侧，提供“编辑、删除” |

- 当前分组无标签时显示“当前分组暂无标签”，并提供“添加标签”按钮。
- 点击使用客户数量跳转客户列表，并携带标签名称及企业微信标签ID作为筛选条件。
- 客户数量及明细必须经过当前用户客户数据权限裁剪。

### 4.2 添加标签

- 点击“添加标签”打开当前分组标签弹窗。
- 支持输入单个标签后点击加号加入待保存列表，也支持“批量新建”。
- 单个标签名称最多15个字；当前分组内以及本次待新增列表内不可重名。
- 批量新建每行一个标签，自动去空行、去重并排除当前分组已存在标签。
- 单次最多新增20个标签；至少添加一个标签后才能保存。
- 保存后创建或更新本地映射并同步至当前企业主体；企业微信部分失败时保留逐条结果，允许后续同步补偿。

### 4.3 编辑标签

- 点击“编辑”打开“编辑企微标签”弹窗，只允许修改标签名称。
- 标签名称必填、最多15个字，且不得与当前分组其他标签重名。
- 点击“保存并同步”后同步更新当前企业主体；成功后刷新名称和更新时间。
- 修改标签名称不改变企业微信标签ID，不回收或重建历史客户标签关系。

### 4.4 删除标签

- 点击“删除”必须二次确认，并明确删除结果将同步至企业微信。
- 删除成功后刷新当前分组列表、分组标签数和页面汇总数量。
- 接口失败时保留当前记录并提示失败原因，不得伪造企业微信成功。
- 已删除标签的历史客户关联用于审计追溯，不得错误关联到后续新建的同名标签。

## 5. 全局搜索标签

- 点击右侧“搜索”进入全局搜索模式，不局限于当前分组。
- 搜索框支持模糊匹配标签名称、企业微信标签ID或标签分组名称。
- 搜索结果展示标签名称/ID、标签分组、适用部门、使用客户和固定右侧操作列。
- 搜索结果中的“编辑、删除、使用客户”与分组列表内行为一致。
- 点击“取消”退出搜索并恢复当前分组；无结果时显示“未搜索到匹配标签”。

## 6. 同步企微标签

- 点击“同步企微标签”只同步当前企业主体的企微企业标签及分组。
- 同步按 `CorpID + external_group_id/external_tag_id` 幂等匹配，不以名称作为唯一键。
- 结果反馈新增、更新、失败数量；单条失败不回滚其他成功记录。
- 企业微信接口不可用时保留现有数据并提示失败，不使用空列表覆盖本地有效数据。
- 企业微信侧删除或变更的数据按接口真实结果处理；存在本地未完成编辑任务时进入冲突队列，不静默覆盖。
- “同步完成”是操作结果提示，不作为标签状态字段或列表筛选项。

## 7. 企业主体、权限与审计

- 标签组、标签、适用部门、统计、搜索和同步均按当前 `corp_id` 隔离，不混合不同企业主体的数据。
- 页面查看、新增/编辑/删除分组、新增/编辑/删除标签、同步及客户下钻分别校验操作权限。
- 适用部门决定哪些部门可使用及编辑分组下标签；候选部门须经过当前用户组织权限裁剪。
- 后端必须重复校验主体、组织和操作权限，前端隐藏或禁用按钮不能替代服务端鉴权。
- 新增、编辑、删除、批量删除和同步至少记录主体、对象ID、操作人、操作时间、前后值、请求ID和结果。
- 页面加载失败与空数据必须区分；失败保留当前主体和搜索条件并允许重试。

## 8. 验收标准

1. 菜单和页面名称统一为“企微标签”，页面不展示系统标签来源和企微个人标签。
2. 左侧标签组支持名称搜索，右侧只展示当前分组标签。
3. 新增分组必须填写15字以内名称、至少一个适用部门和至少一个标签；适用部门支持多选。
4. 点击适用部门或三点菜单“编辑”可修改分组名称和适用部门。
5. 三点菜单展示“编辑、删除”；非空分组无法删除并提示先清空内容。
6. 批量删除模式只能选择空分组，未选择、确认和取消状态正确。
7. 添加标签支持单条及逐行批量新建，单个名称最多15字、单次最多20个、分组内不可重名。
8. 标签支持编辑名称、删除及同步企业微信，企业微信标签ID保持稳定。
9. 全局搜索可按标签名称、企微标签ID和分组名称查询，并展示分组及适用部门。
10. 点击使用客户数量进入已按对应标签筛选的客户列表，数量和明细符合数据权限。
11. 点击同步企微标签仅处理当前企业主体，重复同步不产生重复标签或分组。
12. 空数据、无搜索结果、加载失败、同步失败和部分成功均有明确且不同的反馈。
