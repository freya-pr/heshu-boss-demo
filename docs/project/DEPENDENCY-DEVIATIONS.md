当前生成环境未安装 Node、Java、Maven、Docker，无法在线核验提示词中部分未来版本。

为保证项目可安装，样板选择成熟兼容基线：

| 组件 | 目标 | 样板版本 | 说明 |
|---|---|---|---|
| Spring Boot | 4.1.x | 3.4.5 | 4.1.x 在当前离线环境无法核验；3.4.x 支持 Java 21 |
| MyBatis-Plus | 3.5.16 | 3.5.12 | 当前采用可核验的 Spring Boot 3 Starter 兼容版本，正式安装时再确认 3.5.16 |
| Vue | 3.5.38 | ^3.5.13 | 使用兼容范围，安装时由 lockfile 固化 |
| Vue Router | 5.1.0 | ^4.5.0 | Vue Router 5 无法离线核验，采用稳定 4.x |
| Element Plus | 2.14.2 | ^2.9.7 | 使用稳定兼容范围 |
| Axios | 1.31.1 | ^1.8.4 | 使用当前稳定 1.x |
| Pinia | 3.0.4 | ^3.0.1 | 使用兼容 3.x |
| MySQL | 8.0.46 | 8.0 Docker tag | 由镜像补丁版本更新 |
| Redis | 7.0.15 | 7.0-alpine | 保持 7.0 系列 |

首次安装成功后必须提交 lockfile，并在正式开发前完成许可证与安全扫描。
